# Getting help

Read the [setup guide](docs/getting-started.md), [product specifications](docs/product-specifications.md) and [known limitations](docs/known-limitations.md) first.

For a reproducible problem with a built-in feature, open a [GitHub issue](https://github.com/lixonic/Siftwell-Shopify-theme/issues). Include the theme version, page type, browser/device, steps, expected result and actual result. Screenshots can help; remove private store and customer information.

This is a community project in pre-release development. Support is best effort, with no guaranteed response time. Custom design work, third-party apps, payment providers and Shopify account administration are outside community theme support.

For vulnerabilities or sensitive details, follow [SECURITY.md](SECURITY.md). Never post credentials or customer information. No support email-delivery backend is included in this repository.
