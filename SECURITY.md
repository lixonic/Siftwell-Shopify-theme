# Reporting a security issue

Email **lixonic@gmail.com** with a description, affected version and a minimal reproduction. Do not open a public issue with credentials, customer data or an exploitable store-specific detail.

Never send a Shopify password or Theme Access token. Use sample data and explain the impact without targeting another merchant's store.

Siftwell is currently in pre-release development. There is no guaranteed response time or supported-version schedule yet. A disclosure acknowledgement and remediation plan will be agreed through the private conversation.
